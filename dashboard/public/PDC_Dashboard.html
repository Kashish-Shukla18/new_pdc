Getting Started

The PDC Monitoring Console aggregates synchrophasor data from every Phasor Measurement Unit (PMU) deployed in the Indian transmission grid and presents it to operators at the five Regional Load Dispatch Centres (NRLDC, WRLDC, SRLDC, ERLDC and NERLDC) as well as the National Load Dispatch Centre (NLDC).

Use the left sidebar to switch between monitoring tabs. The header always shows the current IST time, frame rate, and overall system state. A pulsing green dot indicates the master PDC is healthy and ingesting frames.

First time here? Start with Overview — it shows the live national picture in one screen and is the page most operators leave open all shift.

Navigating the Console

Overview

The national map, KPIs, frequency trend, and active alerts. Hover a marker on the map to see substation and PMU info; click to drill in.

Device Inventory

Searchable list of every registered PMU. Filter by region, voltage class, vendor or status. Click a row to open the device drawer for full details and historical metrics.

Data Frames

Decoded IEEE C37.118.2 frames — configuration and live data — for any selected PMU. Useful for verifying that a newly commissioned PMU is sending the expected channels.

Connectivity

Per-PMU network health (latency, jitter, packet loss, availability) and auto-generated remediation suggestions. The recommendations panel is the fastest way to triage problems.

Analytics

Wide-area phenomena — voltage angle differences, low-frequency oscillations, islanding risk and bus voltage profile — with operator advisories.

Status Icons & Colours

Status colours used consistently across the console:

  • Healthy — PMU reporting at full FPS, <1% packet loss, time sync OK
  • Degraded — partial frame loss, high jitter, or quality flags set
  • Offline — no frames received within the missing-frame timeout (default 30 s)
  • Info — informational only, no action required

PMU Shows Offline — Troubleshooting

  1. Open the Connectivity tab and find the PMU in the matrix. Confirm Last Frame timestamp.
  2. If Last Frame is recent but status is "Offline" — the alarm threshold may be too strict; check the device drawer for FPS drop.
  3. From a shell, ping the PMU IP shown in the Devices tab and verify reachability through both primary and HSR backup paths.
  4. Check the substation router for SNMP traps; the most common root cause is a fibre cut on the OPGW link.
  5. If reachable but no frames — restart the PMU stream from the master PDC (pdctl restart stream <id>).
  6. Persistent offline > 15 min: raise a P2 ticket with the regional NOC.

Investigating Data Quality

Open the PMU in Data Frames and inspect the STAT word. Bits to watch:

  • bit 13 — Data error (replace value with last good)
  • bit 12 — PMU sync flag (set if PMU is not synchronized to UTC)
  • bits 10-8 — Time quality, see C37.118.2 §6.2.2
  • bits 3-0 — Trigger reason (manual, magnitude, frequency, ROCOF, df/dt, etc.)

Acknowledging Alerts

On the Overview tab, the Active Alerts & Events panel shows all unacknowledged alerts. Click an alert row to assign it to yourself, or use "Acknowledge all" if you're handing off shift. Acknowledged alerts move to the audit trail in Documentation › Audit.

GPS / Time Sync Issues

PMUs depend on GPS-disciplined oscillators (or PTP IEEE 1588). If you see widespread "Time quality" warnings across one substation, the GPS antenna or substation NTP/PTP server is the most likely cause — not the PMUs themselves.

A PMU running without a valid time source must not be used for protection or post-event analysis. The console will downgrade its status to Degraded automatically.

Frequently Asked Questions

What is the difference between a PMU and a PDC?
A PMU (Phasor Measurement Unit) measures voltage and current phasors at a substation and time-stamps them against GPS. A PDC (Phasor Data Concentrator) aggregates and time-aligns frames from many PMUs, applies quality checks, and forwards them upstream — typically PMU → Substation PDC → Regional PDC → Super PDC.
What reporting rates do Indian PMUs use?
Most PMUs in the national WAMS deployment report at 25 fps or 50 fps. Some applications (e.g. transient post-mortem) use 100 fps where the device supports it.
Why are my voltage angle differences increasing?
Angle separation between buses grows with active power flow and reduced inter-tie reactance. Sudden growth often precedes loss of synchronism — see the Analytics tab for trends and thresholds.
Can I export raw frames for offline analysis?
Yes — open the device drawer and use Export → IEEE C37.118 or COMTRADE. Default retention of raw frames is 30 days; aggregated 1-second data is kept for 5 years.
Who can register a new PMU?
Only users with the PDC-Admin role can add or remove PMUs from the inventory. Operators can edit display metadata only.

Glossary

  • PMU — Phasor Measurement Unit (IEEE C37.118 device)
  • PDC — Phasor Data Concentrator
  • WAMS — Wide-Area Monitoring System
  • ROCOF — Rate of Change of Frequency (Hz/s)
  • SOC — Second-of-Century timestamp (UNIX epoch seconds)
  • FRACSEC — Fraction of second + time quality flags
  • RLDC / NLDC — Regional / National Load Dispatch Centre
  • OPGW — Optical Ground Wire (telecom fibre running on transmission tower earth wire)
  • HSR / PRP — High-availability Seamless Redundancy / Parallel Redundancy Protocol (IEC 62439)

1. System Architecture

The Indian wide-area monitoring platform follows a three-tier PDC hierarchy:

PMU (substation, GPS-locked)
   │  IEEE C37.118.2 over TCP/UDP (OPGW / MPLS)
   ▼
Substation / Sub-PDC (time-aligns local PMUs)
   │  C37.118.2 aggregated stream
   ▼
Regional PDC at each RLDC (5 total)
   │  Inter-regional fan-out
   ▼
National / Super PDC at NLDC  ◀──── Operator Console (this app)
   │
   ▼  archival, applications, openHistorian / PI
WAMS Apps:  Linear-State-Estimator, Oscillation-Monitor, Event-Replay, Control

Each tier performs time-alignment, quality decoration, and forwards frames upstream within ≤ 50 ms. The console talks to the National PDC over a stream multiplexer and a REST control plane.

2. C37.118 Protocol

All PMUs in the WAMS programme conform to IEEE C37.118.2-2011 (data) and C37.118.1a-2014 (measurement). The console implements:

  • Configuration frames CFG-1, CFG-2, CFG-3
  • Data frames at 25 / 50 / 100 fps
  • Header frame retrieval (vendor metadata)
  • Command frames (start/stop transmission, request CFG)

Frame structure summary (also shown live in Data Frames):

[SYNC][FRAMESIZE][IDCODE][SOC][FRACSEC][STAT]
[PHASORS...][FREQ][DFREQ][ANALOG...][DIGITAL...][CHK]

3. Data Model

Logical entities used throughout the console:

  • Region — one of NRLDC, WRLDC, SRLDC, ERLDC, NERLDC
  • Substation — physical site with one or more PMUs
  • PMU — measurement device; unique IDCODE across the network
  • Channel — phasor / analog / digital quantity reported by a PMU
  • Stream — TCP/UDP session carrying frames from a source to a PDC
  • Event — alert/alarm raised by a quality or analytics rule

4. REST & Streaming API

Base URL: https://pdc.nldc.in/api/v1

Common endpoints

GET  /devices                       — list all PMUs (filterable)
GET  /devices/{id}                  — full PMU detail + last metrics
GET  /devices/{id}/frames?from&to  — historical raw frames
POST /devices/{id}/command          — start/stop/cfg-request
GET  /alerts?status=open            — active alerts
GET  /analytics/angles              — inter-regional angle pairs
GET  /analytics/oscillations        — current modal estimates
WSS  /stream/{id}                   — live decoded JSON frames

All endpoints require an OAuth2 bearer token with the pdc.read or pdc.write scope. Rate limit: 60 req/min for read endpoints.

5. Operator Runbook

5.1 Start-of-shift checklist

  1. Confirm system state badge in header is green.
  2. Scan Active Alerts — acknowledge or escalate items older than 30 min.
  3. Verify regional availability ≥ 98% on the RLDC cards.
  4. Check inter-regional angle differences on Analytics — note any > 25°.

5.2 Wide-area disturbance response

  1. Freeze a snapshot via Analytics → Snapshot.
  2. Identify epicentre using ROCOF and angle deviations.
  3. Coordinate with affected RLDC; capture C37.118 frames ± 5 min around event.
  4. Open Event Replay for post-mortem after stabilization.

5.3 PMU restoration

Follow the Help section "PMU Shows Offline — Troubleshooting" steps. Persistent issues escalate to PDC-Admin via the WAMS-OPS queue.

6. Admin Guide

6.1 Registering a new PMU

Navigate to Device Inventory → + Register New PMU. Provide IDCODE, substation, voltage class, vendor/model, primary IP, redundant IP, expected FPS, and signal mapping (phasor labels). The console validates that IDCODE is unique and pings both IPs before activation.

6.2 User roles

  • PDC-Viewer — read-only access
  • PDC-Operator — acknowledge alerts, run diagnostics
  • PDC-Admin — register/decommission PMUs, modify thresholds
  • PDC-Security — manage TLS certs, audit log access

6.3 Threshold configuration

Edit /etc/pdc/thresholds.yaml on the master PDC. Reload via pdctl reload thresholds; no restart required.

7. Security & Compliance

  • All inter-tier C37.118 streams encrypted via IPSec tunnels over MPLS.
  • REST & WSS APIs require TLS 1.3 with mutual certificate authentication.
  • Aligned with CEA Cyber Security in Power Sector Guidelines, 2021.
  • NCIIPC compliance: PDC and SCADA classified as Critical Information Infrastructure.
  • Audit log: 7-year retention, write-once storage, hash-chained.
